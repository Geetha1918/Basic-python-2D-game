🍎 Catch the Falling Apple Game
A fun and simple arcade-style game where you catch falling apples in a basket! 🎮 Built using Python and Pygame, this game tests your reflexes as the apples fall faster over time. Can you catch them all?

🚀 Game Features

✅ Simple and engaging gameplay 🎯

✅ Increasing difficulty as the game progresses ⏳

✅ Score tracking – challenge yourself to beat your high score! 🏆

✅ Smooth controls using arrow keys ⌨️

✅ Built with Python & Pygame 🐍


🛠 How to Play:
🎮 Move the basket left and right using the arrow keys.

🍏 Catch the apples to earn points.

⚠️ Missed apples? Be careful! Your score might drop.

💥 As the game progresses, apples fall faster, making it more challenging!
